Metronome & Practice Tones

A steady WebAudio click with accents and tap-tempo, plus clean sine reference tones for tuning by ear.

BPM
Tap the button in rhythm — 4 taps set the tempo.
Time signature

Beat 1 is accented (higher, louder). Press Space to start or stop when you’re not typing in a field.

Practice tones

Reference pitches in equal temperament around A4 = 440 Hz. Tap a note to toggle it — only one sounds at a time.

A4 = 440.0 Hz
No network — clicks and tones are synthesized on your machine with the Web Audio API. Settings stay in local storage.
