# Local Suite v4.1.0

This release formalizes the Local Suite v4.1 deployment that went live on 2026-07-31 from commit `8fa73f1`.

## Flood Risk & Conditions

- Screens one exact, explicitly confirmed U.S. point against FEMA NFHL data
- Shows mapped flood zone and explicit SFHA interpretation without claiming a property is safe
- Adds active NWS flood alerts and nearby NOAA forecast-gauge context
- Uses a two-step address match-and-confirm flow
- Draws the containing FEMA feature with a text equivalent and approximate edge distance
- Keeps per-source failures independent and uses bounded local caches
- Includes deterministic browser coverage and a strict live New Orleans acceptance gate

The GitHub Pages deployment succeeded and the Flood Risk page has been publicly available since 2026-07-31. This retroactive tag and GitHub Release correct the repository's missing formal release metadata; they do not alter the deployed v4.1 code.
